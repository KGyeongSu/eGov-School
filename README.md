# eGov-School

> 지방공무원 선발 교육 시스템

공무원 채용에 직무 능력을 갖춘 인재를 선발하기 위한 **지역 중심 온라인 교육 시스템**입니다.
공시생이 직무 관련 온라인 강좌를 이수하고 평가를 통과하면 선발에 가산점이 부여되는 구조로,
관리자/강사/수강생 3개 권한별 대시보드와 강좌 등록 → 수강 → 평가 → 수료의 전체 학습 흐름을 구현했습니다.

## 프로젝트 선정 배경

> 현재 공무원 채용은 필기시험 위주라서, 직무 능력을 갖춘 인재를 뽑기 어려운 구조입니다.
> 채용이 인재혁신처에서 일괄적으로 이루어지다 보니, 각 지역에 맞는 인재를 뽑기가 쉽지 않습니다.
> 직무 관련 온라인 교육을 이수하고 평가를 통과해 선발에 가산점을 주는 **지역 중심의 교육시스템**이 있으면 좋겠다는 생각에서 주제를 선정하였습니다.

<br>

## 프로젝트 목표

- 권한별(관리자/강사/수강생) **대시보드 운영**
- 강좌 등록 → 수강 → 평가 → 수료의 **전체 학습 흐름** 구현
- **Spring Security** 기반 역할별 접근 제어
- 강의실 생성 및 커리큘럼/영상 관리, 관리자 강좌 **승인 체계** 구현
- 시험 출제/자동 채점 및 **가산점 기준 설정**

## 주요 기능

### 공통 기능 (메인 / 로그인 / 수강신청 / 게시판)
- **메인 페이지**: 교육과정 카드 리스트, 카드 클릭 시 강좌 상세보기 모달
- **로그인 / 회원가입**: Spring Security 기반 인증, BCrypt 암호화
- **수강신청**: 상세보기 모달(커리큘럼·학습목표·수료조건), 중복신청·마감 체크, 권한별 제한
- **공고 게시판**: 채용공고/시험공고 탭 분리, 관리자 전용 글쓰기 기능

### 강사 대시보드
- **강의실 관리**: 강의명·분야·커리큘럼 차시 등록, 승인 신청 → 관리자 승인 대기, 차시별 영상/자료 업로드
- **시험 출제**: 4지선다 문항 작성, 배점 설정, 제한 시간 설정
- **성적 / 후기 관리**: 수강생 목록 확인, 후기 확인
- **프로필 관리**: 강사 프로필 등록 및 관리

### 수강생 대시보드
- **My 강좌**: 수강 중인 강좌 목록, 진도율 표시 (프로그레스 바)
- **영상 수강**: 차시별 영상 재생, 이어보기 기능, 학습시간 저장
- **시험 응시**: 전 차시 완료 후 응시 가능, 자동 채점 및 결과 확인
- **수강 완료 / 후기**: 수료 강좌 목록, 별점 및 후기 작성

### 관리자 대시보드
- **공무원 선발 가산점**: 가산점 기준 생성 및 리스트 관리, 수강생별 가산점 현황 조회
- **강사 피드백**: 수강생 피드백 확인 및 검색, 강사별 피드백 종합 및 알림 발송
- **강좌 승인 흐름**: 강사 등록 → 관리자 승인 → 수강신청 노출 (교육기간·정원·수료조건 설정)

## DB 설계 (총 24개 테이블)

| 분류 | 테이블 | 설명 |
| :--- | :--- | :--- |
| 사용자 | `USERS` | 회원 정보 (역할: 관리자 / 강사 / 수강생) |
| 강좌 | `CLASS`, `LESSON`, `LESSON_ATTACH` | 강좌 → 차시 → 첨부파일 (영상/자료) |
| 수강 | `CLASSAPPLY`, `PROGRESS`, `LEARNING_STATUS` | 수강신청, 차시별 진도 추적, 학습 상태 |
| 평가 | `TEST`, `QUESTION`, `EXAM_RESULT`, `EXAM_ANSWER` | 시험 출제 → 응시 → 자동 채점 → 답안 기록 |
| 채용/시험 공고 | `JOBNOTICE`, `JOBNOTICE_ATTACH`, `EXAMNOTICE`, `EXAMNOTICE_ATTACH` | 채용공고/시험공고 게시판 및 첨부파일 |
| 강사 모집 | `LECRECRUIT`, `LECRECRUIT_ATTACH`, `LEC_APPLICATION` | 강사 모집공고, 첨부파일, 지원서 |
| 부가 기능 | `REPUTATION`, `SCHEDULE`, `MESSAGE`, `MESSAGE_ATTACH`, `CERTIFICATE`, `BONUS_CRITERIA` | 후기, 일정, 쪽지, 수료증, 가산점 |

## 실행 방법

### 사전 요구사항
- Java 17, Eclipse IDE (m2e 포함), Tomcat 11, Oracle DB

### 실행 방법
1. 저장소를 클론합니다
2. Eclipse에서 Import → Existing Maven Projects로 가져옵니다
3. `jdbc.properties`, `mail-context.xml`을 본인 환경에 맞게 수정합니다
4. Maven install 후 Tomcat 서버에서 실행합니다
